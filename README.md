# shokuinhq/.github

The organization's defaults. Every repository in `shokuinhq` that has no file of its own uses the ones here.

- `.github/ISSUE_TEMPLATE/`: the Bug, Feature and Task forms. Each sets its issue type and adds the issue to the Shokuin project. Blank issues are off; an idea nobody has decided about yet is a draft in the project.

This repository is public, because GitHub reads organization defaults only from a public `.github` repository. It holds process files only: never code, plans or anything internal.
